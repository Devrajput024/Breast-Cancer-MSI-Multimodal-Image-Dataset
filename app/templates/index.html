About the project

Workflow, technologies, and limits

Technologies

  • Python 3.11 and PyTorch
  • torchvision ResNet-18 transfer learning
  • FastAPI backend + static HTML/CSS/JS frontend
  • Pillow, NumPy, pandas, scikit-learn

Project workflow

  • Validate dataset integrity and inspect split leakage risks
  • Train with group-aware splits and save preserved checkpoints
  • Evaluate on held-out test sets and record metrics
  • Serve the original baselines through a research dashboard

Research limitations

  • Models are not clinically validated
  • Cross-modality comparison is not a clinical diagnosis workflow
  • Performance must be interpreted in a research context only

Research use only. Not a clinical diagnostic system.
