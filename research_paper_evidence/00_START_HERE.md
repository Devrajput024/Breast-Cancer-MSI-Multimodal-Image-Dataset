# Evidence package: Breast Cancer Image Classification Using Deep Learning

This package summarizes artifacts inspected in the existing workspace. It is a writing aid, not a validated clinical study. Primary evidence is the saved JSON/CSV outputs and scripts linked in `07_SOURCE_INDEX.md`; README prose and preliminary notes are secondary when inconsistent.

## Navigation
- `01_PROJECT_AND_METHODOLOGY.md`: implementation facts and unavailable settings.
- `02_DATASET_AND_SPLIT_AUDIT.md`: counts, group assumptions, duplicate risks.
- `03_VERIFIED_RESULTS.csv` and `04_RESULTS_ANALYSIS.md`: experiment-separated metrics and interpretation.
- `05_INTERPRETABILITY_AND_AUDITS.md`, `06_APPLICATION_AND_TESTS.md`: audits and app behavior.
- `08_CITATION_AND_REFERENCE_CHECK.md`: citation status.
- `figures/`: copied lightweight confusion matrices; source extracts hold selected scripts and results.

Ultrasound and histopathology are the primary research modalities. Chest X-ray results are exploratory and weak. Do not claim clinical validation, patient-level separation, causal explanations, or external generalization.
